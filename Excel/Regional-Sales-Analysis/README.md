# Regional Sales Analysis Using Microsoft Excel

## Project Overview

An Excel-based sales data analysis project focused on understanding sales performance, identifying business trends and generating meaningful insights from sales records.

## Objectives

- Examine overall sales performance and key business metrics.
- Analyse revenue across regions, cities, product categories and individual products.
- Identify monthly and quarterly sales trends.
- Evaluate customer purchasing patterns.
- Develop visual reports and dashboards to support business decision-making.

## Tools and Techniques

- Microsoft Excel 2013
- Excel formulas and functions
- Data cleaning and preparation
- Sorting, filtering and conditional formatting
- Lookup functions, including INDEX and MATCH
- PivotTables and PivotCharts
- Charts, KPI cards and dashboard visualisation

## Key Areas of Analysis

1. Data quality and preparation
2. Sales metrics and formula-based analysis
3. Date and time-based sales analysis
4. Regional and geographic performance
5. Product and category performance
6. Customer performance
7. Advanced Excel analysis
8. Sales dashboards and management decision-making

## Project Files

- `Regional_Sales_Analysis.xlsx` — Excel workbook containing the analysis.
- `Dashboard_Preview.pdf` — Exported dashboard for quick viewing.

## Limitations

The dataset does not contain transaction IDs, cost, profit, discount or return information. Therefore, profit analysis and definitive unique-order analysis cannot be established from the available data.

## Conclusion

This project demonstrates the application of Excel for data preparation, exploratory analysis, business performance evaluation and dashboard reporting.
